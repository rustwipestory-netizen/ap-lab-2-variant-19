# Лабораторна робота 2.1, варіант 19

Автор: Турків Остап Миколайович, група КН-2630.

Програма обчислює дві формули варіанта 19 і виводить їх результати.
Допустимі значення параметра: a != 0, a != +/-2, a != +/-sqrt(2.5).

## Компіляція та запуск

```sh
g++ -std=c++17 main.cpp -o Lab02Variant19
./Lab02Variant19
```

Також можна відкрити цю папку як CMake-проєкт у Visual Studio.

Результати двох формул мають збігатися.

Десятковий роздільник при введенні - крапка.

https://github.com/rustwipestory-netizen/ap-lab-2-variant-19
